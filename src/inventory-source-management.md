# Inventory Source Management

An **inventory source** is a physical or logical location a seller holds stock in — a warehouse, a store, or a default location. Each seller manages their own sources, and stock for every product is tracked per source.

::: info What you'll learn
- What an inventory source is
- How a seller creates and manages sources
- How sources relate to product stock
:::

## Managing sources

From the Seller Panel, open **Inventories → Inventory Sources**. Every seller starts with a **Default** source and can add more.

<ImagePopup src="/images/inventory-source-management/inventory-sources.png" alt="Seller inventory sources list" />

The list shows each source's **ID**, **code**, **name**, **priority**, and **status**. Use **Create Inventory Source** to add one — you give it a code and name, set its **priority** (which source is drawn from first), mark it **active**, and add its location/contact details.

## Sources and stock

Stock is held per source: when a seller sets a product's quantity, they set it against a source. A product's total availability is the sum across its sources. Manage those quantities from [Manage Inventory](/manage-inventory), and set them on a product's **Inventories** tab in [Product Management](/product-management#the-product-form).

::: tip
Keep priorities meaningful — the marketplace draws stock from higher-priority sources first, so order your sources the way you actually want them fulfilled.
:::
