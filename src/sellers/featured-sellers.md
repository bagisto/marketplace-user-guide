# Featured Sellers

Featured Sellers spotlights a set of sellers on the storefront — an **Our Featured Sellers** showcase — to give strong or promising sellers extra visibility. The admin turns it on and sets how sellers are chosen; the selection is then automatic.

::: info What you'll learn
- What Featured Sellers does
- How the admin enables and tunes it
:::

## Enabling and tuning

In the admin panel, go to **Configure → Featured Sellers**.

<ImagePopup src="/images/featured-sellers/featured-sellers-config.png" alt="Featured Sellers configuration" />

- **Status** — turn the featured showcase on or off.
- **Limit Count** — how many sellers to feature (for example, **12**).
- **Popularity Criteria** — how featured sellers are chosen (for example, **All**), so the marketplace surfaces sellers automatically by that measure rather than by hand-picking.

Save the configuration, and the storefront shows the featured sellers accordingly.

::: tip
Featured placement rewards performance — a seller earns it through good ratings and sales, which tie back to [Rating Management](/moderation/rating-management) and [Seller Account Health](/sellers/seller-account-health).
:::
