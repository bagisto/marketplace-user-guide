# Bulk Upload

Bulk Upload lets a seller add many products at once from a spreadsheet, instead of creating them one by one. Uploads run in the background and report their progress, so a large catalog can be listed in a single pass.

::: info What you'll learn
- The two kinds of bulk upload and when to use each
- How to run an import and track its progress
- Where sample files help you format your data
:::

## Starting a bulk upload

From the Seller Panel, open **Catalog → Bulk Upload**. The **Imports** screen asks how you want to add products in bulk, with two options:

<ImagePopup src="/images/bulk-upload/imports.png" alt="Bulk Upload imports screen" />

- **List Your Own Products** — bulk-create brand-new products in your catalog from a spreadsheet.
- **Sell Catalog Products** — add products already in the marketplace catalog to your store, at your own price and stock (the bulk version of [Selling Existing Products](/selling-existing-products)).

Pick the one that matches what you're uploading, then upload your file to create the import.

## Running the import

Each upload becomes a record under **Past Uploads**, showing the uploaded file, its **type**, its **state**, when it completed, and a **summary** of results.

A typical import moves through a few steps:

1. **Create** the import by choosing a type and uploading your spreadsheet (and product images, where needed).
2. **Validate** — the file is checked for errors before anything is created. If rows fail validation, you can download an **error report** to see what to fix.
3. **Start** — valid rows are imported in the background. The summary updates as products are created.

::: tip Use the sample files
Each import type offers a downloadable **sample file** (and sample images archive). Start from the sample so your columns line up exactly with what the importer expects — it's the quickest way to avoid validation errors.
:::

## After the upload

Imported products behave like any other seller product: they land in **Catalog → Products** and go through the normal [approval flow](/product-management#approval) before appearing on the storefront. You can edit stock and pricing afterwards from [Manage Inventory](/manage-inventory) and [Manage Pricing](/manage-pricing).
