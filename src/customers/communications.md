# Communications

Communications is the direct message channel between a seller and the marketplace **admin**. Instead of email back-and-forth, questions, requests, and clarifications happen in one threaded conversation inside the Seller Panel.

::: info What you'll learn
- Who a seller talks to here
- How the conversation works
:::

## Messaging the admin

Open **Communication** in the Seller Panel. It's a chat thread with the admin — type a message, attach a file if needed, and send. Past messages stay in the thread, and you can search back through them.

<ImagePopup src="/images/communications/communication.png" alt="Seller–admin communication thread" />

The admin has the matching view on their side, so replies appear in the same conversation. This keeps everything — onboarding questions, policy clarifications, payout queries — in one place tied to the seller.

::: tip
Use Communication for anything that needs the admin's attention directly. For customer-facing conversations about a return, use the message thread on the [RMA request](/orders/return-merchandise-authorization) instead.
:::
