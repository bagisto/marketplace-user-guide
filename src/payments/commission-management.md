# Commission Management

Commission is how the marketplace earns from each sale. On every seller order, the platform keeps a percentage as commission and the seller receives the remainder. The admin sets the rates; the split is calculated automatically on each order.

::: info What you'll learn
- Where the marketplace commission rate is set
- How per-seller rates override the global default
- How commission appears on orders and payouts
:::

## The global commission rate

Go to **Configure → Marketplace → General**. The **Admin Commission Percentage** is the default rate applied to seller sales across the marketplace (for example, **20%** means the platform keeps 20% of a sale and the seller earns 80%).

<ImagePopup src="/images/commission-management/commission-config.png" alt="Marketplace general settings with Admin Commission Percentage" />

The same screen also carries the marketplace **status**, the **seller panel logo**, the **subscription** switch, and the installed **module version**.

## Per-seller commission

The global percentage is the default, but the admin can set a **different commission rate for an individual seller** on that seller's admin edit form. A per-seller rate overrides the global default for that seller — useful for negotiated rates or preferred partners. Subscription plans can also carry their own commission terms — see [Seller Subscriptions](/subscriptions/seller-subscription-management).

## Where commission shows up

Commission is calculated per order at the time of sale. You can see it on:

- The **[order list and detail](/orders/order-management)**, alongside each order's gross amount and the seller's earning.
- The **[Seller Payout Management](/payments/payment-management)** view, which totals commission earned and what each seller is owed.

::: tip
Set the global **Admin Commission Percentage** first as your baseline, then adjust individual sellers only where you've agreed a special rate.
:::
