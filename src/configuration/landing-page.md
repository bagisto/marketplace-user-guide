# Landing Page

<div class="page-roles"><span class="role role--admin">Admin</span></div>

The **Landing Page** screen fills the marketplace landing page, the page that
invites visitors to open a shop. Customers reach it from the store icon in the
storefront header.

Go to **Configure >> Marketplace >> Landing Page**.

Titles and descriptions are saved for each channel and language, so write them in
every language your store uses. Images and the four highlight figures, including
**Business Hour**, are saved for each channel. Images must be JPEG, PNG or BMP files.

## Banner

<ImagePopup src="/images/configuration/landing-banner-highlights.png" alt="Banner and Highlights sections of the Landing Page settings" />

| Setting | What it does |
|---|---|
| **Banner Title** | The large heading at the top of the page. |
| **Banner Description** | The text under the heading. |
| **Banner Button Title** | The button that opens the seller sign-up form. A seller who is already signed in sees **Visit Shop** instead, which opens their Seller Panel. |
| **Banner Image** | The picture beside the heading. |

## Highlights

The four figures under the banner.

| Setting | Shown on the page as |
|---|---|
| **Community Count** | The number of sellers, with **Seller Community** under it. |
| **Business Hour** | Your opening hours, such as 24x7, with **Online Business** under it. |
| **Payment Duration** | How many days sellers wait for payment, with **Days\* Payment** under it. |
| **Serviceable Pincode** | How many postcodes you deliver to, with **Serviceable Pincode** under it. |

## Features

<ImagePopup src="/images/configuration/landing-features.png" alt="Features section of the Landing Page settings" />

A heading, a description and an image, then four boxes. Each box has an icon, a
title and a description, set with **Feature Box 1 Icon**, **Feature Box 1 Title**,
**Feature Box 1 Description** and so on up to box 4.

## Seller Journey

<ImagePopup src="/images/configuration/landing-journey.png" alt="Seller Journey section of the Landing Page settings" />

A heading and a description, then five steps. Each step has an icon, a title and
a description, set with **Journey Step 1 Icon**, **Journey Step 1 Title**,
**Journey Step 1 Description** and so on up to step 5.

## Save the page

Every title, description and button title is required, and so are **Business Hour**
(letters and numbers only, such as 24x7), **Payment Duration** and
**Serviceable Pincode**. **Community Count** and the images are optional.

Click **Save Configuration**. The landing page shows your changes straight away.

See [Marketplace Landing Page](../storefront/marketplace-landing-page.md) for how
the page looks to visitors.
